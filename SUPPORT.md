# Getting help

Atlas Pulse is maintained by one person, so help is best effort and there is no guaranteed response time.

| You have | Where to go |
| --- | --- |
| A question about setup or use | Check [Troubleshooting](README.md#troubleshooting) first, then ask in [Discussions → Q&A](https://github.com/socraticsurge/atlas-pulse/discussions/categories/q-a) |
| A bug | Open a [bug report](https://github.com/socraticsurge/atlas-pulse/issues/new?template=bug_report.yml) |
| An idea or feature request | Start a [Discussion in Ideas](https://github.com/socraticsurge/atlas-pulse/discussions/categories/ideas) or open a [feature request](https://github.com/socraticsurge/atlas-pulse/issues/new?template=feature_request.yml) |
| A security vulnerability | Report it privately as described in [SECURITY.md](SECURITY.md). Never in a public issue or Discussion. |
| A Code of Conduct concern | Email the address in the [Code of Conduct](CODE_OF_CONDUCT.md) |

For bugs, the [list in CONTRIBUTING.md](CONTRIBUTING.md#reporting-bugs) says what to include: steps to reproduce, your OS, browser and Node.js version, the AI engine and model if it's an AI issue, and any errors from the browser console or the terminal.
